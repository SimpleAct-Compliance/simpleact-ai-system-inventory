# Inventory Field Dictionary

This field dictionary defines the minimum useful structure for an AI system register.

## system name

The human-readable name used across product, engineering, compliance, and reporting.

## internal ID

A stable identifier that avoids confusion when names change.

## intended purpose

The practical business purpose of the AI system or feature.

## business owner

The function accountable for why the system exists and whether it should continue to operate.

## technical owner

The function accountable for implementation, integrations, and change coordination.

## compliance owner

The function responsible for review, evidence quality, and escalation when obligations change.

## provider

The vendor or internal source delivering the AI capability.

## model or API dependency

The underlying AI service, model family, or integration dependency.

## deployment environment

Where the system operates, such as internal workflow, production SaaS environment, or testing.

## reassessment triggers

The events that require the record to be reviewed, such as model change, new use case, new geography, or new stakeholder impact.
