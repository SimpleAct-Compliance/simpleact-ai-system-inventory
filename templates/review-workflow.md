# Review Workflow

AI compliance is not a document, it is a system.

Use this workflow to keep the AI inventory current.

## 1. Intake

Create the inventory record when a new AI system, provider, feature, or workflow enters scope.

## 2. Owner Assignment

Assign business, technical, and compliance ownership.

## 3. Dependency Check

Record provider, model, API, and infrastructure dependencies.

## 4. Review Trigger

Determine whether the system should move into classification, documentation, or escalation review.

## 5. Periodic Refresh

Review the record on the defined cadence or whenever a trigger event occurs.
