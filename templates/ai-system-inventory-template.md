# Vorlage: Inventareintrag

Ein Eintrag **je System und Einsatzzweck**. Ein Werkzeug, das in drei Fachbereichen für drei Zwecke läuft, braucht drei Einträge.

Leerfelder sind kein Ergebnis. Was nicht bekannt ist, bekommt **nicht bewertet** plus Person und Termin. Erklärung zu jedem Feld: [Felderklärung](./inventory-field-dictionary.md)

## Betroffene und Wirkung

| Feld | Eintrag |
|---|---|
| Betroffenenkreis | |
| Was die Ausgabe auslöst | |
| Vorschlag oder Festlegung? | |
| Übernahmequote des Vorschlags, geschätzt | |
| **Berührt Beschäftigung, Bildung, Kreditwürdigkeit, Strafverfolgung, Migration, Justiz, wesentliche Dienstleistungen oder kritische Infrastruktur?** | ja / nein, welcher |

Ein Ja in der letzten Zeile ist der Fall, in dem die Organisation nach Art. 25 unbemerkt **Anbieter** eines Hochrisikosystems werden kann. Die Zeile gehört bewertet, bevor das System läuft.
