# AI System Inventory Template

Use this template to register AI systems consistently within the Simpleact AI Governance Framework.

## Identity

- system name
- internal ID
- business unit
- lifecycle status

## Purpose

- intended purpose
- use case summary
- affected users
- customer-facing or internal

## Ownership

- business owner
- technical owner
- compliance owner

## Dependencies

- provider
- model or API dependency
- infrastructure dependency
- linked vendors

## Governance

- deployment environment
- review cadence
- last review date
- next review date
- reassessment triggers

## Notes

- classification status
- documentation references
- monitoring notes
